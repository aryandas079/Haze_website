# HAZE Browser Website

The official website of **HAZE Browser**, a privacy-focused browser built around a custom Chromium engine. HAZE aims to deliver fast, smooth, and secure browsing through a minimalist interface and built-in privacy features.

## Features

* Privacy-focused browsing experience
* Built-in ad and tracker blocking
* Custom Chromium-based browsing engine
* Smooth media playback and modern web compatibility
* Available for Android and Windows

## Purpose

This website serves as the central hub for HAZE Browser, providing information about the project, its features, downloads, and privacy policies.
